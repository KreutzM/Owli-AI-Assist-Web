# Security

Please report vulnerabilities privately to the repository maintainer instead of opening a public issue.

Never include real access tokens, provider keys, session tokens, scene images, questions, model answers, or user identifiers in a report. Use synthetic reproduction data.

Security-sensitive areas include browser-to-backend CORS, bootstrap/session binding, rate limits, image validation, service-worker caching, CSP, Audio-Postcard sharing URLs, and future server-side video rendering.
